Companion radios

Used for polling and the remote console. Add one companion per network/frequency (e.g. 909 and 910). Each node uses the radio chosen on its page, or picks one automatically: the companion that heard it most recently, then a companion whose MQTT regions match where it was heard, then the one that last polled it; if a poll fails, the next companion is tried. Each radio has its own hourly polling budget.

Notifications (ntfy)

Install the ntfy app on your phone and subscribe to the same topic. On ntfy.sh, anyone who knows the topic can read it, so use a long random name, or your own server with a token.

Alerts open the node page and offer “Open node” / “All alerts” buttons. Resolved alerts arrive quietly (low priority). The summary uses the timezone under General ({{ general.timezone }}).
